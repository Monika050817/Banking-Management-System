\# Banking Management System



A Banking Management System developed using Java, Spring Boot, Spring JDBC, JSP, JavaScript and PostgreSQL.



\## Technologies Used



\- Java

\- Spring Boot

\- Spring JDBC

\- MVC Architecture

\- JSP

\- HTML

\- CSS

\- JavaScript

\- PostgreSQL

\- Maven

\- Git \& GitHub



\## Modules



\- Admin

\- Employee

\- Customer



\## Features



\- User Registration

\- Login and Authentication

\- Customer Management

\- Employee Management

\- Account Management

\- Deposit

\- Withdrawal

\- Fund Transfer

\- Transaction Management

\- Admin Dashboard

\- Customer Dashboard

\- Employee Dashboard
